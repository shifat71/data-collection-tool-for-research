# trust-hook

A lightweight developer trust measurement tool. Installs a git `post-commit` hook that surveys AI-assisted coding usage and records it to Supabase. Zero dependencies, one command to install.

```sh
npx ./trust-hook
```

**Full documentation lives at the [repository root README](../README.md)** — architecture, Supabase setup, the complete data schema, privacy notes, and troubleshooting.

**Just here to install and use it day to day?** See the [Developer Guide](./DEVELOPER_GUIDE.md) for a shorter, usage-only walkthrough.
